# CRIS Utilidades — Infraestrutura AWS com Terraform

Infraestrutura como código (IaC) desenvolvida com **Terraform** para provisionamento dos recursos utilizados pelo projeto **CRIS Utilidades** na AWS.

## 📋 Sobre o projeto

Este projeto tem como objetivo automatizar a criação e configuração da infraestrutura AWS necessária para a aplicação, utilizando Terraform para garantir que os recursos possam ser provisionados de forma padronizada, reproduzível e versionada.

## 🛠️ Tecnologias

* **Terraform**
* **Amazon Web Services (AWS)**
* Amazon VPC
* Amazon EC2
* Amazon S3
* Internet Gateway
* NAT Gateway
* Route Tables
* Availability Zones
* Elastic Block Storage
* Elastic Load Balancing

* Uso de Docker, Spring e MySql
